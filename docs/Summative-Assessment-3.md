# Summative Assessment 3


## Web Map

In this third summative assessment, you are required to make a web map, using your own basemap, data (either your own or data given to you in class), and interactive elements.

Each map must be accompanied by a short c. 1000 word essay explaining your design choices for your base map, along with other choices you made, debugging you undertook, and what you tried to do (even if it did not work).
